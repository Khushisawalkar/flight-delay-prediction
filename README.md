# ✈️ Flight Delay Prediction System

A machine learning-powered aviation analytics platform built with Python, Streamlit, Scikit-learn, XGBoost, and Plotly.

## Features

- Real-time flight delay prediction
- Interactive Streamlit dashboard
- Airline and airport analytics
- Weather impact analysis
- Route performance insights
- ML model comparison and evaluation
- Explainable AI predictions
- Synthetic dataset generation

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- XGBoost
- Pandas
- NumPy
- Plotly

## Project Structure

```bash
flight-delay-prediction/
│
├── app.py

├── dataset/
├── models/
└── utils/
    ├── preprocessing.py
    ├── prediction.py
    ├── analytics.py
    └── visualizations.py
```

## Installation

```bash
git clone https://github.com/Khushisawalkar/flight-delay-prediction.git
cd flight-delay-prediction
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
